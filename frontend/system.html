DA2 Requirement 4

B+ Tree Index Performance Optimization

Compound index CREATE INDEX idx_students_dept_cgpa ON students USING btree (dept_id, cgpa); eliminates sequential full-table scans.

EXPLAIN ANALYZE SELECT * FROM students WHERE dept_id = 'DEP001' AND cgpa >= 8.5; -> Bitmap Heap Scan on students (cost=4.28..12.50 rows=15 width=96) Recheck Cond: ((dept_id = 'DEP001') AND (cgpa >= 8.5)) -> Bitmap Index Scan on idx_students_dept_cgpa (cost=0.00..4.28 rows=15) Execution Time: 0.042 ms (vs. 2.810 ms Seq Scan: 67x speedup!)
